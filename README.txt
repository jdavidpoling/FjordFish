Welcome to Fjord Fish. The computer vision north Atlantic marine faunal dataset paired with the Coast Watch "North Atlantic Species Classification" project: https://github.com/jdavidpoling/North-Atlantic-Species-Classification.
This is a dataset of imagery from baited and unbaited remote underwater video from the Norwegian and Swedish North Atlantic coastlines and acts as a dataset for computer vision model training as well as:
  - model testing and validation
  - model pretraining
Annotations are contained in text files currently in the You Only Look Once (YOLO) format for YOLOv8+
